# ui-popup-guide

一个关于**前端 UI 弹出提示组件选型**的 Skill：帮你分清 Tooltip、Toast、Alert、Modal、Popconfirm、抽屉（Drawer）到底该在什么场景用哪个，以及常见的防坑规范。

## 包含内容

- 五大高频弹出组件速查表（定位 / 触发 / 是否打断 / 场景）
- 选型标准：按「内容长短」和「是否需要对照原页面」两步决策，弹窗 vs 抽屉 vs 新页面
- 三条防坑铁律：别默认点蒙层关闭、破坏性操作要二次确认、按钮用具体动词
- 提交前的弹窗自查清单

## 作为 Skill 使用

把本仓库作为 Skill 目录，或将其中的 `SKILL.md` 放入工作区的 `.trae/skills/ui-popup-guide/SKILL.md` 即可在本地生效。

```
.trae/skills/ui-popup-guide/
└── SKILL.md
```
